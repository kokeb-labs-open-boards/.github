# Getting help

| You want to | Go to |
| --- | --- |
| Ask how to use a board or a library, or discuss an idea | [Discussions](https://github.com/orgs/kokeb-labs-open-boards/discussions) |
| Report a defect in a design, a library part or a block | An issue in the affected repository, using the board defect form |
| Ask for a new board, part or circuit block | The **Board request** form in any repository |
| Report a vulnerability | Privately, as [SECURITY.md](SECURITY.md) describes |

Before asking, read the board's documentation (`docs/` and `board.yml` in its repository), in particular its status
and errata. Include the board name and revision, the firmware and driver versions, and what you measured.

Kokeb Labs Open Boards is maintained by a small team. Answers in Discussions come on a best-effort basis; there is
no paid support channel yet, and no board is sold or supported as a product until its repository says it is released.
