# kokeb-labs-open-boards/.github

The front door of the Kokeb Labs Open Boards organization.

| Path | What it is |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The page shown at <https://github.com/kokeb-labs-open-boards> |
| [`CONTRIBUTING.md`](CONTRIBUTING.md), [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md), [`SECURITY.md`](SECURITY.md), [`SUPPORT.md`](SUPPORT.md), [`GOVERNANCE.md`](GOVERNANCE.md) | Community files. GitHub shows them in every repository that has none of its own |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE), [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Default issue forms and PR template for every repository |
| [`.github/DISCUSSION_TEMPLATE/`](.github/DISCUSSION_TEMPLATE) | Forms for the discussion categories |
| [`docs/adr/`](docs/adr) | Decisions for this organization, such as the hardware licence |
| [`TRADEMARKS.md`](TRADEMARKS.md) | How the name and logo may be used |

The engineering standard, the brand files and the settings of this organization are kept in
[`kokeb-labs/.github`](https://github.com/kokeb-labs/.github): see its
[`standards/`](https://github.com/kokeb-labs/.github/blob/main/standards/README.md),
[`brand/`](https://github.com/kokeb-labs/.github/blob/main/brand/README.md) and
[`org/`](https://github.com/kokeb-labs/.github/blob/main/org/README.md).

Changes go through a pull request like any other repository.
